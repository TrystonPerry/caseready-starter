# CaseReady workshop

Read `AGENTS.md` and follow `GUIDE.md`. The attendee uses Claude Desktop Code
in Local mode, starting from a downloaded GitHub ZIP or a clone.

For Cloudflare account setup, authentication, and deployment, follow
`CLOUDFLARE_SETUP.md`. Explain the steps and run local Void commands. The attendee
must operate all account browser screens themselves. Never use Chrome control,
computer use, or browser automation for signup, login, verification, authorization,
or billing. Use only Void for deployment.
